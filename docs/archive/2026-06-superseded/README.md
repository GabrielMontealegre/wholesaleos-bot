# Superseded rule files (history only)

These files were the agent rules from June 2026. Several of them contradicted the current way of
working (Dallas-only adapters, no merges or pushes without approval, "1–2 comps = locked", no new tabs,
ending every task with a prompt for Gabriel, obsolete UI architecture). They were retired on 2026-10-01.

Do not follow them. `AGENTS.md` at the repository root is the operating manual; its §12 lists the
retired rules so they are not re-added. Useful content (evidence gates, comp buckets, keep-don't-discard,
plain-English UI, production verification) was folded into `AGENTS.md`.
