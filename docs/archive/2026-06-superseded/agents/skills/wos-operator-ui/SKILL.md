# wos-operator-ui

Use this when changing the main dashboard, leads workflow, analyzer cards, modal text, or bulk actions.

- Keep the main UI simple for a normal real estate operator.
- Avoid backend, admin, engineering, or debug language in the main workspace.
- Keep technical actions under Admin / System Tools or hidden secondary surfaces.
- Use plain next-step language: what Gabriel should do now.
- Do not add clutter, fake dashboards, or engineer-only bulk action bars.
