# Mistake Log

Use this file to prevent repeated product and evidence mistakes.

## Known Mistakes To Avoid

- Treating generic search/category pages as property-specific proof.
- Letting source candidates disappear silently instead of creating Manual Review Queue rows.
- Counting source estimates, nearby values, tax assessments, list prices, or auction bids as comps.
- Letting subject property sale/listing evidence count as its own comparable sale.
- Calling candidate evidence "verified" before source proof exists.
- Using vague reasons like "public source signal" instead of exact criteria.
- Adding operator controls to the main Leads workspace.
- Adding new nav tabs when existing Scout, Analyzer, and Daily Call Pipeline surfaces can carry the workflow.
- Treating Auction.com/listing marketplaces as official proof.
- Assuming buyer match strength when valuation is missing.

## Required Correction Pattern

When a candidate is not ready:

- keep it visible
- classify it accurately
- explain the blocker
- send it to manual review if it may be repairable
- keep valuation locked
- do not create fake fields to make it look better
