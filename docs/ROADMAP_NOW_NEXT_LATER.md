# Roadmap Now Next Later

## Now

Prove the selected-deal preview can execute evidence gathering.

- Verify property source from selected address or URL.
- Find visible contact route without fake or paid data.
- Run bounded comp research.
- Capture repair evidence from visible source text.
- Return before/after canonical Opportunity.
- Keep all writes disabled.

Add paid-data decisions for:

- skip trace
- comp data
- owner/entity resolution
- property facts

Connect Opportunity output to a dashboard view only after preview output is
useful and stable.

## Next

Build the operator workflow around canonical Opportunities.

- buyer engine
- title company workflow
- persistent Opportunity queue
- follow-up loop tied to Opportunity state
- selected-lead comp workflow
- paid data switches with clear cost controls

## Later

Scale only after the money path works for Gabriel.

- nationwide source coverage
- more adapters
- deeper automation
- queue workers
- buyer matching automation
- title workflow automation
- dashboard expansion

## Explicit Deferrals

Do not prioritize these until selected-deal execution produces useful output:

- more generic source adapters
- abstract SaaS onboarding
- broad nationwide crawling
- dashboard widgets without execution value
- automation that writes records without reviewed evidence
