# wos-model-routing

Use this when choosing a model or planning a Codex task.

- Use GPT-5.5 High for major architecture, multi-file refactors, source agents, comp engine work, and hydration/load-order debugging.
- Use GPT-5.4 Mini for validation, deployment checks, syntax checks, browser QA, summaries, and small bug fixes.
- Do not waste GPT-5.5 High on repetitive verification.
- When giving Gabriel a plan, include: model, prompt purpose, what to verify, whether to commit/push, and the safe commit summary.
