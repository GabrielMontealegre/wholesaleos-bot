# wos-source-repair

Use this when an address is junk, partial, missing, or otherwise not ready for valuation.

- Bad addresses are not trash.
- Send them to Needs Research, Source Repair Needed, or Comps Blocked.
- If a source URL exists, preserve it for property identity repair.
- Do not value bad or junk addresses until the property identity is repaired.
- If the source is useful, explain how it helps repair the record.
