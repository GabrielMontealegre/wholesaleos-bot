# wos-evidence-gates

Use this when working on leads, analyzer jobs, comp research, valuations, or any workflow that can imply property facts.

- Never invent comps, ARV, MAO, owner, debt, DOM, sold price, listing history, or source evidence.
- Candidate comps do not unlock valuation.
- ARV requires verified sold comps.
- MAO requires ARV plus repair evidence.
- If evidence is missing, show it as missing instead of fabricating a result.
- Preserve evidence gates even when the UI or backend is incomplete.
